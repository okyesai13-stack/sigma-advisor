# Project Architecture Rules

- Keep business logic inside existing page/context modules while shared visual language lives in semantic CSS tokens and reusable UI primitives, so redesigns cannot alter the Supabase workflows.
- Store whiteboard section positions, dimensions, removed-section keys and connections alongside notes in lean_canvas boxes.__board; use shared geometry helpers so resizing, movement, membership and mapping stay consistent without changing agent workflows. Single-section deletion removes contained notes, while bulk deletion clears all board notes with an undo snapshot; both retain analysis results and tasks. Recreation restores saved section geometry.
- AI credit balances change only through database security-definer functions (spend_credits/refresh_credits); AI edge functions charge via _shared/credits.ts before calling the model, so the browser cannot skip or alter charges.
- Startup roadmaps live in their own startup_roadmap table (one row per business), generated by the startup-roadmap edge function and edited client-side, so whiteboard saves to lean_canvas cannot overwrite them.

- Execution workspaces use ProjectEngineContext and relational projects/tasks with membership RLS, version-checked task writes and trigger-generated activity; legacy analyses remain in WorkspaceContext so execution edits never overwrite whiteboard JSON or agent results.
- Use the existing whiteboard and roadmap editors only for legacy board tasks and milestones; relational execution tasks use dedicated project editors and completed-task-only progress.
- Paginate Supabase execution reads in stable 500-row batches and list rendering in 25-row pages to avoid silent default query truncation; future large-workspace search should move to server query filters.
- Use dnd-kit sensors for Kanban movement with optimistic version-checked persistence and rollback; never store board status only in browser state.
- Preserve the strategy dossier at /analysis and support legacy /dashboard#section-* links while /dashboard displays the project overview; synchronize route project IDs into the business context so advisor queries use the opened project.
- Use SidebarProvider for navigation and a closed-by-default right advisor panel on wide desktop or Sheet on smaller screens; main workspace width is never permanently reserved for AI.
